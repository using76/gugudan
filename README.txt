구구단 챌린지 — 사용 방법
==========================

이 폴더 하나로 윈도우 PC와 안드로이드 폰에서 모두 쓸 수 있습니다.
(인터넷 없이도 동작하고, 글꼴·소리가 모두 파일 안에 들어 있습니다.)

1) 윈도우에서 바로 쓰기
   - index.html 을 더블클릭하면 크롬/엣지에서 게임이 열립니다.
   - 바탕화면에 바로가기를 만들어 두면 앱처럼 쓸 수 있습니다.

2) 앱으로 설치하기 (안드로이드 · 윈도우 공통, 추천)
   이 폴더를 HTTPS 웹 공간에 올리면 '설치형 앱(PWA)'이 됩니다.
   - 가장 쉬운 방법: https://app.netlify.com/drop 에 이 폴더를 끌어다 놓기
     (또는 GitHub Pages 등 아무 HTTPS 호스팅)
   - 안드로이드: 크롬으로 주소 열기 → 게임 첫 화면의 [이 기기에 앱으로 설치하기]
     또는 크롬 메뉴(⋮) → '앱 설치' / '홈 화면에 추가'
   - 윈도우: 엣지/크롬으로 주소 열기 → [이 기기에 앱으로 설치하기]
     또는 주소창 오른쪽의 설치 아이콘 → 시작 메뉴·작업 표시줄에 앱 아이콘 생성
   - 한 번 설치하면 인터넷이 없어도 실행됩니다.

3) 플레이스토어용 APK / 윈도우 설치 파일(MSIX)이 필요하면
   2)번처럼 올린 주소를 https://www.pwabuilder.com 에 넣으면
   안드로이드 패키지와 윈도우 패키지를 만들어 줍니다.

참고
   - 순위 기록은 기기(브라우저)마다 따로 저장됩니다.
   - PC에서는 키보드 숫자, Enter(확인), Backspace(지우기), Esc(그만하기)도 됩니다.
